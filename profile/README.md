# Строка · Strokka

**Платформа поиска компаний и контактов по базе организаций РФ.**

Поиск на естественном языке, фильтры по контактам и реквизитам, выгрузка в CSV/CRM и API для интеграций. Контакты собираются из открытых источников.

🌐 [strokka.com](https://strokka.com) · 🖥 [Кабинет](https://app.strokka.com) · 📚 [Документация](https://docs.strokka.com) · ✉️ vlad@strokka.com

---

## Возможности

- 🔎 **Поиск** — запрос обычными словами: «производители мебели с email в Москве»
- 🤖 **Агент «Скрепка»** — AI-агент собирает выборку компаний диалогом
- 📇 **Данные** — реквизиты, сайты, города, отрасли и публичные контакты
- 📤 **Экспорт и API** — CSV/CRM, REST API с ключами, MCP для AI-инструментов
